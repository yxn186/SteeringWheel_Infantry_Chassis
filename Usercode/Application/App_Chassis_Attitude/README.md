# 底盘与云台姿态关系

`App_Chassis_Attitude`在底盘板上注册一个只读GM6020对象，接收CAN2上的云台Yaw电机反馈。该对象只解析`0x204 + Motor ID`反馈帧，不调用电机组发送接口，因此不会向云台Yaw电机发送控制命令。

云台相对底盘Yaw由电机编码器角度、机械零位和方向系数计算。底盘世界系Yaw由底盘BMI088提供，两者相加得到云台世界系Yaw。机体系约定为X轴向前、Y轴向左、Z轴向上，Yaw逆时针为正。

平移目标先在云台坐标系中生成，再按照云台相对底盘Yaw旋转到底盘坐标系。这样普通模式和小陀螺模式均可保持“以云台正方向为前方”的操作方式。

拨杆组合：

- 左中、右上：右摇杆控制云台，左摇杆控制云台坐标系下的底盘平移。
- 左中、右中：普通模式，左摇杆控制云台坐标系平移，右摇杆X控制底盘旋转。
- 左上、右下：小陀螺模式，左摇杆控制云台坐标系平移，底盘按照固定角速度自旋。
- 左上、右中：底盘跟随云台，底盘Yaw闭环消除云台相对底盘角。

Yaw电机ID、机械零位和方向位于`App_Chassis_Attitude_Config.h`。该机械零位必须与云台工程的Yaw机械零位保持一致。
